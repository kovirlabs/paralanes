## Open questions for Evan

1. **`stagelanes` name.** A Nim concurrency library `ghazalialshafi/stagelane`
   (16 stars, created 30 Oct 2026, active today, four repos built on it) is a
   near-collision in the same field. The plural is free on crates.io and
   GitHub. Keep `stagelanes`, or pick another name? PLAN.md lists no spare
   for the stage runtime.
2. **Gap wording.** PLAN.md says vendor-neutral GPU data ops "exist almost
   only for NVIDIA". The check says that is too strong. Should PLAN.md and the
   README be reworded as above?
3. **FFT for M7.** VkFFT (through `gpufft`) and `wgsl-fft` already do FFT on
   Vulkan, Metal and wgpu. Benchmark them before building our own?
4. **`vyre`.** A crate (0.7.2) with wgpu and CUDA drivers, a CPU reference
   oracle and a CRC-32 op; its GitHub repo returned 404, so its scope could
   not be checked. Closest Rust overlap with `bytelanes`.
